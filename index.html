How it works

三步，三秒

不用背 ID，不用切窗口，不用翻 Wiki。

01

按 G 打开面板

游戏内任意时刻呼出，不切窗口、不离开建造。

02

打中文就能搜

全拼、首字母、多音字混合匹配，1500+ 方块毫秒出结果。

03

勾选即出指令

自动拼好 //set 或 //replace，一键复制进剪辑板。

Features

四件真正省时间的事

不是功能清单，是每天建造都会用到的四个动作。

shanzhang 多音字命中
闪长岩 minecraft:diorite ✓

智能拼音搜索

全拼 shibou、首字母 st、多音字 shanzhang / shanchang 都能命中「闪长岩」。中文名、英文 ID、拼音混着打也认。

相对权重 · 输入值即实际比例
石头 50圆石 25沙砾 25

权重精确控制

三个方块输入 50 / 25 / 25，就是精确的 50% / 25% / 25%。采用 WorldEdit 原生相对权重语义，互不干扰。

常用方块收藏

点 + 加入常用、点 − 移除。列表存在 config/block_id.json，换存档、重装游戏都还在。

//replace stone 50%dirt,50%grass
minecraft:stone_slab[type=top]

WorldEdit 深度集成

支持方块属性与放置权重；1.20.1 检测到 WorldEdit 还能直接执行，不用复制粘贴。

Install

两分钟装完

纯客户端模组，服务器和整合包都不用改。

  1. 01装好对应版本的 Forge 47.4.10+（或 Fabric 0.15.11+）
  2. 02把 jar 放进 .minecraft/mods 文件夹
  3. 03启动游戏，按 G 打开面板开始搜方块
  4. 04可选：装 WorldEdit，解锁 //set 一键执行
  1. 01装好对应版本的 Fabric Loader 0.15.11+（或 Forge 47.4.10+）

FAQ

装之前你可能想问

不需要。Block ID 是纯客户端模组，服务器和整合包都不用改动；单人、多人服务器都只装在本地即可。

不是必须。不装 WorldEdit 也能搜索方块、查看 ID、复制 //set / //replace 指令；装了才能在游戏内直接执行（1.20.1 支持检测并一键执行）。

目前支持 Minecraft 1.20.1 与 1.19.2，两个版本都提供 Forge 与 Fabric 两种加载器，共 4 个 jar。

目前未发现冲突。打开面板默认是 G、复制 ID 是 H；如与其它模组键位重复，到 设置 → 控制 → 按键绑定 的「方块ID」分类里重绑即可。
